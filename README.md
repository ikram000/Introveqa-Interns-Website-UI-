Introveqa Interns Website UI

This project is a landing page UI for the Introveqa Interns Website, developed as part of a Web Development Internship task. The website provides a clean and modern interface where users can learn about internship programs and apply through a simple application form.

Features
Responsive Landing Page UI
Internship Programs Section
Apply Button Functionality
Application Form Interface
Success Message After Form Submission
Clean and user-friendly design
Functionality

When the user clicks the Apply button, the application form opens. After filling out the form and submitting it, a success message is displayed to the user.

⚠️ Note: This project currently focuses on UI design only. The form submission does not store data in a database.

Technologies Used
React.js
HTML
CSS
JavaScript
Purpose

The main goal of this project is to demonstrate frontend UI development skills using React as part of an internship assignment.
